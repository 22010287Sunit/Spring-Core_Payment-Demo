# Spring Core Payment Demo

A small Java project for learning Spring Core using XML-based configuration.

## Goal

Build a simple payment system using multiple payment implementations and gradually introduce Spring Core concepts.

## Technologies

- Java 17
- Maven
- Spring Core
- IntelliJ IDEA

## Learning Progress

- [x] Project setup
